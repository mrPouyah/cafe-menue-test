# منوی هوشمند کافه دی

A mobile-first Persian RTL smart coffee menu prototype built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## GitHub Pages Deployment

This project is configured for static GitHub Pages hosting.

1. Create a GitHub repository.
2. Push this project to the repository's `main` branch.
3. In GitHub, go to `Settings` -> `Pages`.
4. Set `Build and deployment` -> `Source` to `GitHub Actions`.
5. Push again or run the `Deploy to GitHub Pages` workflow manually.

For a project repository, the app automatically uses `/<repo-name>` as its GitHub Pages base path during GitHub Actions builds. Local development still runs at `/`.
